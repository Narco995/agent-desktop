# Agent Desktop

High-end **mobile-first** virtual desktop for AI agents (Claude, ChatGPT, Grok, and more).

## Features (Current Foundation)

- Beautiful multi-window environment
- Fully responsive — feels native on phone
- Dock + floating Agent Orb
- Draggable windows (desktop)
- Full-screen adaptive windows on mobile
- Agent chat interface (ready for real APIs)
- Notes & Files apps
- PWA-ready

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000
